### 1. [Skill Constellations: Tracing the Supply Chain of Agent Skills on GitHub](https://arxiv.org/abs/2610.11169)
- **Source:** arXiv (preprint, University of British Columbia Okanagan; full text read) · published 2026-10-08
- **Matches:** skills and ways of packaging instructions for agents (core); agent security (core)
- **Why it's here:** Rebuilds the copy network behind about 2.2 million SKILL.md adoptions on GitHub and finds that skills spread by bulk copying with no versioning. Only about a fifth of copies pick up later fixes from their source. Auditing repositories by copy out-degree prevents far more later high-risk adoptions than auditing the most-starred ones (14.9% vs 0.5%).

### 2. [How Snyk turned an internal support agent into a customer feature](https://www.langchain.com/blog/how-snyk-turned-an-internal-support-agent-into-a-customer-feature)
- **Source:** LangChain blog (Oliver Armstrong) · published 2026-10-08
- **Matches:** running evals in CI as a release gate (core); scoped tool permissions (core); LangGraph (core)
- **Why it's here:** A production case study of one LangGraph agent used across Slack, web and API. Tools are attached per request based on the signed-in user's permissions, and every PR runs graded eval suites that block the merge when they miss thresholds kept in the repo. A scheduled job also grades every production run. The metrics are self-reported and it is hosted on LangChain's own site, but the architecture is concrete.

### 3. [Introducing Claude Haiku 5.5](https://www.anthropic.com/claude-haiku-5-5)
- **Source:** Anthropic · published 2026-10-07
- **Matches:** new model releases (core); routing between cheap and strong models (core)
- **Why it's here:** Anthropic's new small model is priced at $0.10/$0.50 per million input/output tokens for prompts up to 100K, roughly 90% cheaper than Haiku 4.5 at that size. It is the first Haiku with an adjustable effort setting, and the vendor table shows large jumps over Haiku 4.5 (for example OSWorld 72.4% vs 15.7%). Anthropic positions it for subagents, classification and compaction, but not for complex agentic coding. The same post halves Sonnet 5.5 cache-read prices.

### 4. [Revamping Skills in Deep Agents](https://www.langchain.com/blog/revamping-skills-in-deep-agents)
- **Source:** LangChain blog (Sydney Runkle) · published 2026-10-07
- **Matches:** skills and context engineering (core); prompt caching (core)

### 5. [What is Codemode](https://lucumr.pocoo.org/2026/10/6/codemode/)
- **Source:** Armin Ronacher · published 2026-10-06
- **Matches:** agent harnesses and tool execution (core); MCP server design (core)
- **Why it's here:** Ronacher explains why his Pi harness added Codemode, a QuickJS-in-WebAssembly sandbox where the agent writes JavaScript that calls tools and MCP servers without passing every intermediate result through context. The post separates the trusted harness ("brain") from the execution environment ("hands") and ends with concrete requests to MCP server authors: stable JSON shapes, `outputSchema`, binary support, and a way to search tools across servers.

### 6. [From Evidence to Action: How Tool-Using Agents Fail](https://arxiv.org/abs/2610.07753)
- **Source:** arXiv (preprint, Princeton, NUS, HKBU and AWS; full text read) · published 2026-10-06
- **Matches:** trajectory evals for agents (core); deterministic tests for LLM code (core); agent failure modes (core)
- **Why it's here:** SafeActBench (656 cases) replays trajectories against a provenance-bound evidence ledger using a deterministic evaluator, not an LLM judge, which disagreed with human labels about 2% of the time. Models that score 95–99% on static allow/block judgments drop to 28–52% when they have to gather evidence and act themselves. They often act before the evidence is in, and harness choice can help or hurt depending on the model.

### 7. [EmbeddingGemma 2: an open, lightweight multimodal embedding model](https://blog.google/innovation-and-ai/technology/developers-tools/embeddinggemma-2/)
- **Source:** Google DeepMind (The Keyword blog) · published 2026-10-06
- **Matches:** embedding model choice for RAG (core); notable small open models (core)
- **Why it's here:** A 740M-parameter Apache 2.0 embedding model, with a 270M text-only configuration, that maps text, code, images, video and audio into one space. It has 8K context and Matryoshka truncation from 768 down to 128 dimensions. Google reports MTEB Code rising from 68.76 to 78.68 and pitches it for local code search and on-device RAG.

### 10. [AdvSim2Real: Training Web Agents Against Adaptive Prompt Injection in a Web World Model](https://arxiv.org/abs/2610.08773)
- **Source:** arXiv (preprint, MBZUAI, Amazon and MIT; full text read) · published 2026-10-06
- **Exploring:** Agent security and real-world failure modes (adjacent)
- **Because:** you liked Wikimedia's report on agents misbehaving on live sites; this studies attackers who plant instructions on the pages agents read
- **Why it's here:** Inside a simulated web, the authors co-train a task curriculum, an attacker that picks when to inject based on what the agent is doing, and a 4B web agent. Under a held-out Kimi-K3 attacker, completion rises from 23% to 31%. The authors say a large gap between clean and attacked runs remains, and the robustness gains were not tested in a real browser.
